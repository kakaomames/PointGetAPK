## 🇺🇸 English

### 99% Return & 100% Transparent Rewarded App
Traditional rewarded apps exploit users by taking massive cuts and opaque commissions. **Open Poikatsu Project** breaks this norm. We return **99% of all ad revenue directly to the users**, keeping only a transparent **1% operator fee** for maintenance. 

### 💡 Core Features
- **99% Payout Ratio:** Almost all ad earnings go straight to your balance.
- **Fully Open Source:** Every single line of backend and frontend code is public. No hidden tricks, zero fraud.
- **Dynamic Pricing:** Automatically adjusts rewards based on real-time ad auction rates.

### 🛠 Tech Stack
- **Backend:** Python (Flask) + SQLite
- **Client:** Android (Kotlin)
- **CI/CD:** GitHub Actions (Automated APK Build)
